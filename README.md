# xtop

80 列终端里的只读资源监控。要求 Python 3.10+，默认由标准库实现，无第三方依赖。

## 安装

```sh
pip install dist/xtop-0.1.0-py3-none-any.whl
xtop
```

推荐安装 NVML 后端，GPU 查询更轻量、稳定；未安装时自动回退到
`nvidia-smi`：

```sh
pip install '.[gpu]'
```

开发时：

```sh
pip install -e .
```

## 用法

```sh
xtop                    # 主机每 1 秒采样，界面每 0.25 秒刷新
xtop -d 2               # CPU、磁盘、网络、进程每 2 秒采样
xtop --refresh 0.5      # 界面刷新间隔，秒
```

GPU 使用独立频率：NVML 指标/进程为 1/2 秒，`nvidia-smi` 回退为 2/4 秒，
设备和挂载拓扑每 30 秒刷新。一次查询失败时保留最近成功数据，连续失败会
逐步退避到最多 30 秒。没有 GPU 或驱动时静默跳过。

`q` 退出，空格暂停显示，`r` 立即刷新，`s` 切换进程排序，方向键滚动。

## 显示

顶栏是主机、运行时间、load、任务数。下面每类设备一行：

- CPU 占用，内存占用和用量
- 每张 GPU 一行：占用、显存、温度、功耗
- 有 IPv4 地址的网卡：上下行带宽
- 物理磁盘：挂载点、读写带宽、空闲、总量

其余空间是进程表，包含 root。列为 PID、USER、CPU、MEM、RSS、COMMAND。数字
右对齐，单位紧贴数字；终端变窄时进程命令从右侧直接截断。

界面使用终端默认前景和背景色，不设置任何颜色。摘要区使用固定列宽，不随
终端宽度重排；设备名在列内直接裁切，整行超出屏幕时从右侧自然截断。

## 数据来源

`/proc` 读 CPU、内存、磁盘、网络和进程。GPU 优先使用可选的 NVML Python
绑定，失败时调用 `nvidia-smi`，两者都没有则跳过。GPU 在独立线程采集，
驱动超时不会阻塞界面和主机信息。磁盘只统计有硬件节点的整盘，挂载点
通过 sysfs 的 device-mapper 名字还原。
